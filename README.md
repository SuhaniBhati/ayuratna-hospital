# 🌿 Ayuratna - Hospital Web-Portal

Ayuratna is a **modern hospital administration web portal** built with **React (.jsx)** and **Tailwind CSS**.  
It is designed for hospitals to manage patients, doctors, staff, appointments, payments, and integration with **HIS (Hospital Information System)** and **EHR (Electronic Health Records)**.  

The portal provides a clean, modern, and Ayurveda-inspired user experience using a **brown & beige themed color palette** with accents of teal.
## 🚀 Features

### 🔹 General
- Modern UI inspired by Ayurveda aesthetics.  
- Built using **React (.jsx)** and **Tailwind CSS**.  
- Uses **dummy data + local storage** to simulate real hospital workflows.  
- All patient and hospital data is securely handled.  

### 🔹 Authentication
- Hospital Signup with **National Identification Number (NIN)** validation.  
- Strong password creation with complexity rules.  
- **Two-Factor Authentication (2FA)** via email OTP.  
- Secure login, forgot password, and forgot NIN/username flow.  

### 🔹 Landing Page
- Hero section with Ayurveda-themed image and "Get Started" + "Learn More" buttons.  
- Learn More page explains **how to operate the system** with better formatting.  
- Footer with contact info and **social media links** (dummy).  
- Animations on feature cards for interactivity.  

### 🔹 Hospital Admin / Receptionist Portal
- **Dashboard**: Overview of hospital activities.  
- **Appointments**: Manage doctor availability and patient bookings.  
- **Doctors**: Add, edit, and assign doctors by department.  
- **Patients**: View and manage patient profiles.  
- **Reports**: Generate hospital-wide patient diet & treatment trends. 

### 🔹 Security & Compliance 
- Secure authentication with **JWT sessions + 2FA**.  
- **HIPAA/GDPR compliant encryption** for patient data (encrypted at rest and in transit).
